# Стартовый промпт для Claude Code

Открой эту папку в Claude Code (вкладка Code → Local → Open folder… → эта папка) и вставь текст ниже:

---

Привет! В этой папке лежит всё для сайта-портфолио моей сестры, актрисы Марии Дмитриевой.
Сначала внимательно прочитай `CLAUDE.md` — там полное ТЗ. Потом посмотри
`reference/studio-prototype.dc.html` (рабочий прототип концепции на CSS 3D: все тексты, логика,
переходы, спецрежимы), `reference/scene.json` (координаты предметов, позы камеры) и картинки
`reference/views/*.jpg` (как должен выглядеть каждый ракурс).

Задача: собрать настоящий сайт на Vite + React + TypeScript + Three.js (react-three-fiber, drei,
postprocessing, GSAP). Прототип — только референс, не копируй его CSS 3D: он лагал и терял
куски фона, поэтому делаем WebGL.

Порядок:
1. Составь короткий план и структуру проекта, покажи мне, потом начинай.
2. Сцена: павильон, пол, стены, видео на экране, все предметы на своих местах, метки на скотче.
   Сверь с `reference/views/*.jpg` через скриншоты из браузера.
3. Камера: интро (отсчёт 3-2-1 → титр на экране → отъезд), поворот головы + проход к предмету
   с покачиванием, хлопушка, панели разделов.
4. Все разделы и режимы из ТЗ: About, Portfolio (плёнка + контактный лист), Showreel
   (видоискатель), Projects (HEART + билеты), Contacts (финальные титры + форма), Backstage,
   Wardrobe, Action!, дыхательное упражнение, blooper reel, звук, ч/б ⇄ цвет.
5. Производительность (60 fps), мобильная версия, доступность, «Skip 3D»-версия, мета-теги.
6. Запусти dev-сервер, сам проверь каждый экран скриншотами, исправь баги, сделай `npm run build`.

Весь текст на сайте — на английском. Тексты, которых ещё нет, оставь плейсхолдерами в [скобках]
и вынеси весь контент в один файл `content.ts`, чтобы потом просто вставить настоящие тексты и фото.
Если что-то в ТЗ неясно — сначала спроси.
